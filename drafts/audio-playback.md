# 语音播报 — 设计文档

> 来源：[探索记录 2026-07-25](./2026-07-25.exploration.md)

## 目标

通过 MAX98357A I2S 功放 + 小喇叭，实现基本的语音提示。
**聚焦异常告警**（低电量、PS2 断连），而非模式切换播报。

## 硬件

- **MAX98357A**：I2S 输入单声道 D 类功放
- **小喇叭**：8Ω / 3W 以下即可
- 3 根数据线（BCLK、LRCLK、DIN）+ SD（shutdown 控制）+ 供电

### 引脚分配（ESP32-S3）

| 引脚 | 功能 |
|------|------|
| G38 | DIN |
| G39 | BCLK |
| G40 | LRCLK |
| G17 | SD（Pull up = EN, down = shutdown） |
| 3V3 | GAIN（固定增益 9dB） |
| 3V3 | VCC |
| GND | GND |

### 接线注意事项

- MAX98357A 模块 SD 脚默认拉低（amp shutdown），启动后由 MCU 拉高使能
- GAIN 直接接 3V3 固定增益即可，不需要 MCU 控制
- I2S 信号线尽量等长、远离 TB6612 的 PWM 线

## 软件设计

### 播放内容清单

| 优先级 | 事件 | 音频内容 |
|--------|------|----------|
| 高 | 电池低电量 | 告警音 / "电量低" |
| 高 | PS2 断连 | "手柄断开" |
| 中 | PS2 恢复 | "手柄已连接" |
| 低 | 模式切换 | 可选，可变调蜂鸣代替 |

### 技术路径

1. 预录 PCM 8kHz/16bit/mono 短片段，嵌入固件（或放 PSRAM）
2. 通过 `esp-hal I2S` driver 推流到 MAX98357A
3. 播放期间不阻塞主 loop — 使用 DMA + 中断，或在 33ms tick 中分片 push

### 风险点

- **I2S driver 成熟度**：`esp-hal` 的 I2S 支持需确认版本兼容
- **马达噪声**：行驶中可能听不清，但告警场景（停车切换、掉线）时马达通常为 0
