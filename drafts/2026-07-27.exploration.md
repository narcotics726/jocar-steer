## 已达成决定

### D-001: control.rs → input.rs

- **决定**：`control.rs` 重命名为 `input.rs`，作为统一输入归一化层。
- **职责**：PS2 raw → 归一化语义值（死区、摇杆→物理量、按键 edge detection）。
- **与其他模块的关系**：input.rs 产出供所有子系统消费的统一帧结构，不关心消费方是车/飞机/屏幕小人。
- **影响范围**：
  - `control.rs` → `input.rs`（rename）
  - `ControlConfig`、`DriveMode`、纯函数映射、`MotorSlew` 留在 input.rs
  - 新增 `ButtonTracker`（有状态，edge detection）
  - `lib.rs` 更新 `pub mod`

### D-002: 引入 drive_intent.rs 作为语义转换层

- **决定**：在 `input.rs`（逻辑无关）和子系统（Motors/Steering/Lights）之间加一个独立的 `drive_intent.rs` 模块，负责 `InputFrame → DrivingIntent` 的语义映射。
- **原则**：纯函数（无状态）。
- **职责**：把"左摇杆 Y 在 -50"翻译成"油门 39% 前进"、"刹车意图"等驾驶语义。

### D-003: InputFrame 形状

- **决定**：InputFrame 收集一帧内所有外部输入（驾驶员操作 + 传感器观测）。
- **字段**：
  - `controller_connected: bool` — PS2 是否在线
  - `ly: i32`, `rx: i32` — 死区已消化，归一化为 -128..128
  - `pressed: EnumSet<Button>`, `held: EnumSet<Button>` — 按键 edge + 持续
  - `battery: Option<BatteryReading>` — 电池快照，无电池时 None
  - 未来扩展：rpm、IMU 等，加 `Option<T>` 字段即可
- **断连处理**：断连时 `controller_connected = false`，轴值归零，按键清空。语义层看到断连强制 `throttle = 0`。
- **原则**：电池走 InputFrame，不走旁路。低电保护等策略在语义层统一处理。

### D-004: DrivingIntent 形状

- **决定**：DrivingIntent 是语义层对 InputFrame 的解释，纯函数 `(prev_frame, curr_frame, config) → DrivingIntent`
- **字段**：
  - 瞬时值：`throttle: i32`, `steer: i32` — **归一化逻辑量**（-128..128），不做物理量转换
  - 派生布尔：`brake_active: bool`（throttle < 0）, `steer_active: bool`（steer ≠ 0）
  - 状态转换事件：`brake_started: bool`, `brake_ended: bool`, `steer_started: bool`, `steer_ended: bool`
  - 按键映射事件：`headlight_toggle: bool`（Select edge），`left_signal_toggle: bool`, `right_signal_toggle: bool`, `mode_switch: bool`（L3+R3 edge）
  - ~~系统状态（battery_low, controller_connected）~~ — 这些是 resolve() 的输入条件（从 InputFrame 读），不是 DrivingIntent 的输出字段；强制执行结果已表达在 throttle/brake_active 中
- **物理量转换归 main**：`intent.steer * max_deg / 128`、`intent.throttle * max_duty / 128` 等在模式分发处完成
- **名字**："DrivingIntent" 语义过窄（不仅是驾驶意图），但当前够用，暂不改名

### D-006: MotorSlew 暂留 input.rs

- **决定**：`MotorSlew` 属于电机执行层，不应该在 `input.rs`，但本次重构不挪。
- **未来考虑**：当需要 PID / 逻辑 duty→电压映射 等概念时，新建 `motor.rs` 统一收纳 MotorSlew + Tb6612 上层逻辑。

### D-007: PS2 断连走 InputFrame

- **决定**：`controller_connected: bool` 作为 InputFrame 字段，断连也是"外部输入"的一种。
- **影响**：
  - 语义层看到断连 → `throttle = 0, steer = 0`（安全停车）
  - `ButtonTracker` 看到断连 → 清空内部状态（防重连误触发 edge）
  - `StatusLight` 从 `SystemState.controller_connected` 获取连接状态

### D-008: 引入 SystemState

- **决定**：新增 `SystemState` struct，维护"车此刻是什么样"，取代独立的 StatusInput。
- **数据流**：

  ```
  InputFrame ──解析──► DrivingIntent ──修改──► SystemState
    (外部输入)        (驾驶意图)            (系统当前状态)
  ```

- **两路写入**：
  - 系统事实（`controller_connected`, `battery`, `ticks`）→ InputFrame → **直达** SystemState，不走 DrivingIntent
  - 驾驶意图（`throttle`, `steer`, `brake_started` 等）→ DrivingIntent → 子系统 → 写入 SystemState
- **StatusLight 改为渲染器**：`render(state: &SystemState) -> Rgb`，不再需要独立 StatusInput
- **子系统的时序状态**（刹车灯快闪/常亮、转向灯相位）归子系统内部，SystemState 只暴露渲染所需的最小字段

## 实施步骤

### Step 1: input.rs 重构

- [ ] `control.rs` → `input.rs`（rename）
- [ ] 新增 `InputFrame` struct
- [ ] 新增 `ButtonTracker`（有状态 edge detection，内部感知断连防误触发）
- [ ] 新增 `build_frame()` 工厂函数：封装 ButtonTracker + 归一化 + Ps2Event→InputFrame
- [ ] `lib.rs` 更新 `pub mod input`
- [ ] `ControlConfig`、`MotorSlew` 保持不动

### Step 2: 新建 drive_intent.rs

- [ ] 新增 `DrivingIntent` struct
- [ ] 实现 `resolve(prev: &InputFrame, curr: &InputFrame, config: &ControlConfig) -> DrivingIntent`
- [ ] 语义规则集中：
  - brake/shift 方向、边缘检测
  - 按键→事件映射：`Select → headlight_toggle`、`Left → left_signal_toggle`、`Right → right_signal_toggle`、`L3+R3 → mode_switch`
  - `battery_low` / `controller_connected` 强制停车（从 InputFrame 读取，在 resolve 内执行）

### Step 3: main.rs 改造

- [ ] 初始化 `SystemState`（默认值）、`ButtonTracker`、`prev_frame`
- [ ] 主循环调用 `input::build_frame()` 替代直接读取 `Ps2State`
- [ ] 系统事实直达 SystemState：`state.controller_connected = frame.controller_connected` 等
- [ ] 调用 `drive_intent::resolve(&prev_frame, &frame, &cfg)` 产出 `DrivingIntent`
- [ ] 意图驱动执行器 → 写入 SystemState：
  - Mode switch：`intent.mode_switch` → 翻转 `state.drive_mode` + 重置 MotorSlew
  - Motors：`intent.throttle` / `intent.steer` → `state.throttle`, `state.steer_angle`
  - Steering：同上
  - VehicleLights：`lights.apply(&intent, dt)` → `state.headlight_on`, `state.brake_phase`
- [ ] StatusLight 纯渲染：`status.render(&state) -> Rgb`，不再消费 DrivingIntent
- [ ] 更新 `prev_frame = frame`
- [ ] 删除 `mode_switch_held: bool`（由 ButtonTracker edge detection 替代）

### Step 4: VehicleLights（新模块）

- [ ] `lighting/vehicle.rs`：纯状态机
- [ ] 接口：`apply(intent: &DrivingIntent, dt_ms: u16) -> u16`
- [ ] 转向灯：`steer_started` 触发闪烁，`steer_ended` 启动 hold 计时器
- [ ] 刹车灯：`brake_started` 触发快闪 2s，后常亮
- [ ] 大灯：`intent.headlight_toggle` → 翻转内部状态（不感知 Button::Select）

### Step 5: StatusIndicator → StatusLight（重命名 + 接口调整）

- [ ] `ws2812_stat_indicator.rs` → `status.rs`；`Ws2812StatIndicator` → `StatusLight`
- [ ] 接口改为纯渲染：`render(&self, state: &SystemState) -> Rgb`
- [ ] 内部不再维护 `Phase` — 用 `state.ticks` + 模运算计算闪烁相位（或保留局部 Phase，两种都行）
- [ ] 消费 `state.controller_connected`, `state.battery.is_low()`, `state.drive_mode`, `state.ticks`
- [ ] 删除旧的 `StatusInput` struct
