# 电池电压检测 — 设计文档

> 来源：[探索记录 2026-07-25](./2026-07-25.exploration.md)

## 目标

通过电阻分压 + ESP32-S3 ADC 实现电池电压监测，弥补当前完全没有电量感知的盲区。
**支持两套电池配置自动适配。**

## 电池配置

| 类型 | 标称 | 满电 | 告警阈值 |
|------|------|------|----------|
| 2S LiPo | 7.4V | 8.4V | 7.0V |
| 4×AA 碱性 | 6.0V | 6.4V | 4.4V |
| 4×AA NiMH | 4.8V | 5.6V | 4.4V |

## 硬件

### 电路

```
BAT+ ── R1(100kΩ) ──┬── ADC pin (G8) ── R2(47kΩ) ── GND
                      │
                      └── 100nF 电容到 GND（滤除电机噪声）
```

分压比：`V_ADC = V_BAT × 47/(100+47) = V_BAT × 0.32`

| 电池 | 满电 V_BAT → V_ADC | 空电 V_BAT → V_ADC |
|------|--------------------|---------------------|
| 2S LiPo | 8.4V → 2.69V | 7.0V → 2.24V |
| 4×AA 碱性 | 6.4V → 2.05V | 4.0V → 1.28V |
| 4×AA NiMH | 5.6V → 1.79V | 4.4V → 1.41V |

全部在 ADC 0~3.3V 范围内，一套电路通用。

### 引脚

| 引脚 | 功能 |
|------|------|
| G8 | ADC1_CH7，电池电压采样 |

### PCB 注意事项

- 电阻放在靠近 ADC pin 一侧，缩短高阻抗走线长度
- 电容必须贴近 ADC pin
- 分压电阻静态电流 ~57µA（可忽略），不需要开关切断

## 软件设计

### ADC 采样策略

1. 在 TB6612 PWM **off 间隙**采样（与 motor tick 同步，降低电机噪声耦合）
2. 32 点移动平均平滑
3. 每 500ms 更新一次读数即可（电压变化缓慢）

### 自动电池类型识别

```rust
fn detect_battery_type(v: f32) -> BatteryType {
    if v > 7.5 { BatteryType::LiPo2S }   // 阈值 > 7.0V, 告警 = 7.0V
    else       { BatteryType::Aax4 }     // 阈值 > 4.4V, 告警 = 4.4V
}
```

启动时采样一次即锁定类型。边界情况：严重过放的 LiPo（<7V）会误判为 AA，但此时电池已废，不应使用。

### 告警输出

低电量时通过以下渠道报告：

1. 喇叭语音告警（如果有 MAX98357A）
2. WS2812 红灯慢闪
3. defmt 日志

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 电机开关噪声耦合到 ADC | 100nF 电容 + 软件平均 + 同步采样 |
| ADC 输入阻抗不足 | 分压电阻 100k+47k 折中，避免太大 |
| 电池反接 | 电路层面不做保护，靠物理防呆接口 |
