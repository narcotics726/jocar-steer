# 供电稳定性 — 电源方案设计（2026-08-08）

> ## ⚠ 2026-08-15 实际定型（取代下文 1S 方案）
>
> 实际装车方案与下文“已定型 1S”不同，已实车运行：
>
> - **电池：2S 7.4V 锂电** → TB6612 VM 直通；另路 **5V buck** → 板 5VIN（AMS1117 工作正常，7.4V 未经 buck 不碰板子，电容 6.3V 耐压无忧）
> - **马达：12V 额定 N30 4000 RPM**（非 N20），单后驱无差速
> - **接收器 VBUS**：背板 USB-OTG 焊盘短接，取 5V buck 输出（与板 5VIN 同网，2S 下为规范 5V）
> - **发热观察**：马达 3–5 分钟烫手（>60°C）——非电压问题（12V 电机在 7.4V 属欠压），而是**转弯/起步堵转电流**（无差速 + 转向不减油 + 4000RPM 低减速比）。固件已加转向-油门混合 + 起步 kick + 转向角 30° 缓解；结构性正解是加大减速比。
> - 下文 1S/TP5400 方案与 8-08 的“已定型”标记**作废**，保留作为分析记录。

---

> 背景:小车结构改为**单马达 + 传动轴**驱动后轮,前桥(舵机转向)不变。
> 症状:快速摆动舵机或瞬间推满油门 → 电压跌落 → ESP32 重启 → 接收器断连。
> 已确认:只有 7.4/12V 电池才能稳定,但重量超标,不理想。目标:**5V 甚至 3.7V 也能稳**。

## 一、诊断结论(先理解再动手)

- 电压跌落公式:`V_drop = I_peak × (电池内阻 + 线阻 + 接插件接触电阻)`,再叠加稳压器压差。
- **高电压电池"有效"的真实原因不是能量多,而是稳压器输入余量大了**:7.4V 进 BEC 掉 1V 还有 6.4V,输出 5V 纹丝不动;1S 4.2V 进升压掉 1V 就 3.2V,直接失稳。高电压只是"买余量"的手段之一,不是唯一手段。
- **软件侧无操作空间**:no_std esp-hal(rev 667f8f0)未暴露 brownout 配置 API,查过源码只在 S2 sleep 路径内部用到;S3 硅片默认阈值约 2.43V 且是最宽容档。目标 = 让 3.3V 轨不跌破 ~2.5V。

## 二、手段一:电源域分离(最关键,RC 圈标准做法)

**先对齐已知事实(handoff 2026-08-07):板上 LDO 是 AMS1117-3.3,需要 ≥4.4V 输入;3.7V 直供会 brownout 锁死;7.4V 不能直接灌板子(板上电容 6.3V 耐压)。**

含义:

- 1S 想给板子供电 → **必须先把 1S 升到 5V** 再灌 5V/VBUS 引脚(AMS1117 才能工作);
- 或者**绕过板上 AMS1117**,把低 dropout LDO(如 HT7333)输出直接注入 3V3 引脚 —— 但 OTG 口的 USB 接收器要 5V VBUS,板子 5V 轨无电时 VBUS 也没电,所以该路径仍需一个 5V 源(升压)给接收器;
- 马达/舵机的电**永远不**和 ESP32/接收器走同一条未经缓冲的线:

```text
1S 锂电 ─┬─ 直驱 ──── 马达(3.0-4.2V 没问题)
         ├─ 升压5V(2A+,输出大电容) ── 舵机 + USB接收器VBUS
         └─ 低dropout LDO(HT7333 ~90mV / RT9013) ── ESP32 3.3V(绕过板上 AMS1117)
```

- ESP32 的 3.3V 从**电池直接经 LDO**取,路径不经过马达/舵机。1S 满电 4.2V,负载把电池拉到 3.6V 时输出照样 3.3V。
- **重点怀疑对象:板上 AMS1117-3.3(压差 1.1V@1A)**。5V 轨掉到 ~4.3V 以下 3.3V 就崩 → brownout 重启。这是"用高电压才稳定"的最可能元凶。
- USB 接收器要 5V VBUS,与舵机同放 5V 轨没问题,但该轨必须稳(见手段二)——接收器断连的直接原因就是它。

## 三、手段二:储能缓冲(最便宜,治标但有效)

- 5V 轨总入口:1000–2200µF 低 ESR 电解(6.3V 耐压)
- 舵机电源口就近:470µF(舵机是主要电流尖峰源,0.5–1A/几十 ms)
- 马达口:100–470µF
- 各轨配 0.1µF 陶瓷

**量级**:0.5A 持续 100ms 允许掉 0.3V → C = 0.5×0.1/0.3 ≈ 167,000µF,电解做不了——**长瞬态靠域分离,短尖峰靠电容**。
**警告**:别买小体积 5.5V 超级电容(ESR 几十 Ω,对瞬态电流没用);真要超级电容须选低 ESR 大电流规格,一般不值当。

## 四、手段三:源头减瞬态 + 降电阻

- 软件:slew 已有(steering.rs + MotorSlew)。可调:舵机 `update` max_step(现 8°/tick@33ms ≈ 240°/s)调小;马达 512 步/33ms 全油门 ~264ms,已算温和。
- **舵机行程别顶死点**:顶到机械限位 = stall 电流 0.6–1A,最凶的瞬态。检查转向不撞限位。
- 电池选高 C 数(45C+);短粗硅胶线(20AWG);XT30 插头;能焊就焊。
  - **JST-PH + 26AWG 细线是典型瓶颈**(~130mΩ/m),满油门 3A ≈ 0.4V 压降。

## 五、两套具体方案

| 方案 | 接线 | 适合场景 |
| --- | --- | --- |
| **3.7V 1S** | 马达直驱 + 升压 5V(舵机+接收器)+ HT7333 直取 1S 给 ESP32,5V 轨加 1000µF+ | 最轻,但 1S 要算升压余量,略脆 |
| **5V 稳定(推荐)** | 2S 300–500mAh + 5V BEC 输出 5V 轨(马达可直驱 7.4V,扭矩更好) | RC 标准解;重量与大容量 1S 相当,余量直接买来 |

- 注:之前 7.4/12V 测试"成功"时必然是接了 BEC 出 5V 才灌板子的(handoff 明说 7.4V 不能直接灌)——这恰好证明诊断:**稳定来自 BEC 输入余量,不是电池大小**。用 2S 小电池(300–500mAh)+ BEC 效果相同,重量远小于 12V 方案。
- 注:2S 只是把电压翻倍,能量密度和重量与同能量 1S 相当,不是"大电池"。

## 六、建议测量步骤(先量再动手)

## 八、2026-08-08 讨论更新:新底盘 + N20 + TP5400

**底盘/动力变化**:整体换了更小的车架;电机为 **N20 减速电机**(减速比未知,测量方法见下)+ 传动轴;前桥舵机转向不变。

**电池方向**:倾向 **3.7V 1S 锂聚合**(轻薄)。

**已有硬件**:自制 **TP5400 模块**(TP4056 充电 + 5V 升压输出)。

### 1S/2S/3S 是什么

| 叫法 | 电芯数 | 标称电压 | 满电 | 含义 |
| --- | --- | --- | --- | --- |
| 1S | 1 节 | 3.7V | 4.2V | 单节锂聚合物(我们现在的方案) |
| 2S | 2 节串联 | 7.4V | 8.4V | 两节串起来,电压翻倍 |
| 3S | 3 节串联 | 11.1V | 12.6V | 三节串联 |

1S 的电压范围(实用)约 3.3–4.2V;低于 ~3.3V 就该停(亏电会伤电池)。

### TP5400 的约束(重要)

TP5400 是**充电 + 升压一体**的移动电源芯片:充电 ~1A,**5V 升压输出上限约 1A**。

→ 它的 5V 轨**喂不动** 舵机(堵转 0.6–1A)+ ESP32 + USB 接收器同时工作;但**只当逻辑轨**用它绰绰有余(ESP32 + 接收器合计 <0.5A)。

### 修订后的 1S 拓扑(用现有硬件)—— ✅ 已定型(2026-08-08 讨论确认)

**决策:舵机 SG90/MG90S 直驱 1S(3.7V)。**

```text
1S 锂电 ─┬─ TP5400(5V 逻辑轨) ── 板 5V/VBUS 引脚(AMS1117→3.3V) + USB 接收器 VBUS
         │     └─ 模块输出加电容 470–1000µF
         ├─ 直驱 ────── N20 马达(经 TB6612,VM=3.7V 在 2.5-13.5V 范围内)
         └─ 直驱 ────── SG90/MG90S 舵机(3.7V 直驱)
```

- 马达直驱 1S:N20 电流小(空载几十 mA,堵转 ~1-1.5A),直接从电池取,瞬态不碰逻辑轨。

### 电容布置清单(1S + TP5400 方案)✅ 2026-08-08

原则:**大电容(电解)放电源入口和消耗大户口,吸低频大电流瞬态;小电容(0.1µF 陶瓷)放每个有源/开关节点附近,高频去耦。离负载越近越好,引线短粗直接回地。** 按优先级:

| 优先级 | 位置 | 电容 | 作用 |
| --- | --- | --- | --- |
| 1 | **舵机电源口(直驱 1S)** | 470µF 低 ESR 电解 + 0.1µF 陶瓷 | 舵机电流尖峰就地吸收,不回灌电池线(最优先) |
| 2 | TP5400 输出(逻辑轨入口) | 470–1000µF 电解 + 0.1µF 陶瓷 | 逻辑轨缓冲,AMS1117/接收器瞬态 |
| 3 | TB6612 VM 输入(马达电源) | 100µF 电解 + 0.1µF 陶瓷 | 马达 PWM 开关电流的本地回路 |
| 4 | N20 马达端子 | 0.1µF 陶瓷(靠近电刷) | 电弧/EMI;可再加 47–100µF |
| 5 | 板 5V 输入引脚 | 10µF(板上一般自带,可叠加) | 与 TP5400 输出电容配合 |

注意:电解耐压 ≥6.3V(舵机/马达轨最高 4.2V,TP5400 输出 5V,都够);**别在 ESP32 的 3V3 引脚上加大电容**(板上已有去耦,加大会影响上电时序);信号线/USB 差分线上不加。

- **舵机直驱 1S**:SG90/MG90S 低电压可用但力矩/速度下降;小底盘负载轻,很可能够用,且彻底绕开 5V 升压的电流限制 —— 最稳。若力度不够再挪到 5V 轨。
- **共地注意**:三条域(TP5400 逻辑轨 / N20 / 舵机)共电池地,用星形/单点接地,避免马达地弹(GND 弹跳)干扰 USB 差分信号。
- **舵机 3.7V 实操注意**:① 信号线 3.3V 逻辑电平配 3.7V 供电没问题;② 上电时舵机会冲向命令角——固件初始化先发 center,避免上电猛甩(大电流尖峰);③ 转向行程别顶死点(顶死 = stall 电流)。
- **TB6612 兼容性确认**:VM 2.5-13.5V(3.7V ✓),VCC 逻辑 2.7-5.5V(3.3V ✓);单马达只需一路输出。

### N20 减速比测量方法

1. **拆数齿(最直接)**:N20 齿轮箱压合,小螺丝刀撬开,数每级大/小齿,比 = Π(大/小)。常见 1:30 / 1:50 / 1:100 / 1:150 / 1:298。
2. **量转速反推(不拆)**:输出轴贴标记,手机慢动作录像数圈 → 输出 RPM;再查同型裸电机空载 RPM(不同绕组不同,10k–20k 常见)相除。误差大。
3. **其实控制/功率设计不需要减速比本身**:直接量**空载输出转速 @3.7V**(结合轮径算最高车速)和**堵转电流**(决定电源预算)更实用。
4. (可选)ESP32 自己数:输出轴粘磁铁 + 霍尔传感器,GPIO 中断计数打印 RPM。
