# 双模控制 — 需求确认

**日期**: 2025-07-21

## 硬件布局（不变）

```
轴A: 舵机转向 (SG90, G14)
轴B: 双马达独立驱动 (L=G1/G11/G12, R=G2/G9/G10)
```

## 两个模式

| | 模式1 后驱 (Rear) | 模式2 前驱 (Front) |
|---|---|---|
| 车头 | 轴A (舵机) | 轴B (马达) |
| 转向方式 | 舵机 | 马达差速 |
| 驱动方式 | 轴B 双马达同速 | 轴B 双马达差速 |
| 轴A 角色 | 转向 | 从动拖行（舵机回中） |
| 物理操作 | 正常方向 | **调转车身 180°** |

## 行为规格

- **模式切换**：PS2 按键切换（具体按键待定）
- **切换过渡**：先停车（电机 coast + 舵机回中），再切换
- 输入映射见 `03-input-mapping.md`

## 架构决策

方向A（Embassy 多任务拆分）—— **搁置**。当前 30Hz 单循环足够，
多任务引入的同步开销 > 收益。如果将来控制逻辑变得复杂到主循环超过 30ms，
再重新评估。
