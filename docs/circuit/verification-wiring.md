# 验证阶段焊线清单（TB6612 + 2S，2026-08）

拓扑：BAT+ → buck IN+ 与 TB6612 VM；BAT- → 低侧开关 → 共地点（星形，开关后地轨）。
所有负载（电机 + buck 输入）的回流都过开关——2S 下开关总电流 ~3.06A，**开关额定 ≥4A**。

## 电容（跨网络元件，就近焊在对应元件电源脚旁）

```text
{1000µF : VM ↔ 共地点}    # 电解, TB6612 VM 脚旁——必装（上次烧驱动教训）
{0.1µF  : VM ↔ 共地点}    # 陶瓷, 高频去耦
{470µF  : 5V ↔ 共地点}    # 电解, buck 输出端, 舵机瞬态缓冲
{0.1µF  : 5V ↔ 共地点}    # 陶瓷, buck 输出去耦
```

## 上电顺序

1. **不插电机**上电：量 VM ≈7.4V / 5V 轨 ≈5V / 3V3 ≈3.3V
2. 插电机轻推油门：摸 TB6612 与开关温度（验证阶段都不该烫手）
3. 打舵+油门组合：验证转向混合生效（满舵时电机明显降速）
4. 全程留意 5V 轨是否被舵机堵转拉垮（跌出 4.8V 说明 buck 或电容不足）

## 备注

- **开关 3A/250VAC（标 750W）**：750W=3A×250V 交流视在功率。DC 下电压降额只在高电压要紧，8.4V 无虞；约束是 3A 接触电流——2S 峰值 3.06A 踩线可用，但别长时间堵转、别带电拨开关。3S 计划（4.2A）必须换 ≥5A/12VDC。
- 接收器路径若有物理 USB hub：hub 总线供电（从口上 VBUS 取电），下游接接收器——仍无独立电源线；5V 轨电流预算 +0.1~0.3A，MP1584EN 3A 富余
- 固件无需改动：当前 usb-gamepad-car 就是 2S + TB6612 + 转向混合 + 起步 kick 的配置
- AT8236 到货后：仅换驱动芯片/模块 + VREF 限流（~3.5-4A），其余接线不变
